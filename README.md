# 🎮 Jogo do Número Secreto

Projeto desenvolvido durante a **Imersão da Alura**.

O objetivo do jogo é adivinhar um número secreto entre **1 e 10**, com contagem de tentativas e feedback ao usuário.

## 🌐 Deploy

Acesse o projeto online:

https://jogo-beta-umber.vercel.app

## 🎯 Funcionalidades

- Geração de número aleatório
- Sistema de tentativas
- Dicas para ajudar o jogador
- Reprodução de **áudio de voz**
- Interface interativa no navegador

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vercel (Deploy)

## 🧠 Aprendizados

Durante o desenvolvimento deste projeto foram praticados:

- Manipulação do **DOM com JavaScript**
- Lógica de programação
- Geração de números aleatórios
- Interação com o usuário
- Implementação de **áudio em aplicações web**
- Publicação de projetos com **Vercel**
